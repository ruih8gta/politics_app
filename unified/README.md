# 国会マップ — 統合デモ

国会マップ、アトラス版、ニッポン政治勢力図をまとめた独立した統合版です。リポジトリ直下の従来版も引き続き利用できます。

## 起動

リポジトリのルートで `npm start` を実行し、`http://localhost:8000/unified/` を開きます。統合版だけを配信する場合は `npm run start:unified` で `http://localhost:8000/` を開いてください。

ビルド不要のHTML・CSS・ES modulesです。静的ホスティングではこのディレクトリを公開できます。JSONをfetchするため、HTMLの直接ダブルクリックでは動きません。本番表示にnpmパッケージは不要です。

## 6つの画面

| 画面 | 主な機能 | 「政治の基礎知識」で学べること |
| --- | --- | --- |
| 概要 | 政権、与党系会派の議席、支持率、地図、注目政策、日程 | 国会と内閣の関係、与党・野党、過半数・3分の2、支持率 |
| 全国マップ | 地域・会派選択、選挙時の党派と名簿時点の会派の切り替え、関係図 | 国会の役割、衆参の違い、会派と政党、小選挙区と比例代表 |
| 政策・争点 | 政策5件、6争点×10政党の公約比較、12政党から1〜3党を選ぶ公式資料比較 | 公約・法案、委員会・本会議、成立・施行、予算・財源、閣議決定 |
| 議員を探す | 711人の氏名・読み・選挙区検索、会派・地域・比例の絞り込み、公式プロフィール | 国会議員の仕事、地方議員との違い、選挙制度、合区 |
| リーダー・内閣 | 12政党のリーダーと主要閣僚、基準日・確認日・出典 | 党首・首相・大臣の違い、首相指名、内閣改造と政権交代 |
| 政治日程 | 予定の時系列表示、今後／全日程の切り替え | 通常・臨時・特別国会、会期、解散と任期満了、統一地方選挙 |

各画面の控えめな「政治の基礎知識」ボタンから、そのテーマに関連する政治の解説が開きます。操作マニュアルではなく、短い文章・関係図・比較図・折りたたみの用語説明・公式解説へのリンクで政治の仕組みを学ぶ補助コンテンツです。PCでは右側のパネル、スマホでは全画面表示です。閉じるボタン、Esc、背景クリックで閉じ、元のボタンへフォーカスを戻します。検索条件や現在の画面は保持します。

モバイル向けレイアウト、ライト／ダーク配色、ブラウザの戻る操作、議員データのダウンロードにも対応します。テーマ設定だけをlocalStorageに保存し、バックエンド・追跡分析・ユーザー登録はありません。

## データと資料時点

| ファイル | 内容 |
| --- | --- |
| `data.json` | 国会マップの公式議員名簿と地図。衆院464人（2026-09-28）、参院247人（2026-11-02）。欠員各1 |
| `policies.json` | 12政党・4分野の公式政策要約。原則2026年、公明2025年、立憲2021年 |
| `leadership.json` | リーダーと確認済みの関係。2026-11-04確認 |
| `snapshot.json` | 元リポジトリの政権・閣僚・支持率・日程。2026-11-03収録 |
| `issues.json` | 元リポジトリの政策進捗と選挙公約比較。2026-11-03収録 |
| `election.json` | 2026-02-08衆院選・小選挙区当選時の党派 |
| `seat-layout.js` | 元リポジトリの`js/lib.js`から継承した議席面積の配置・検証処理 |

元リポジトリの参照コミットは `3005fc5c9b30ebb922bd8c29c22ed019463d3e2d` です。上記データは独立したスナップショットで、ルートの`data/`とは自動同期しません。

会派の人数・議席図は公式名簿を基準とし、欠員を加えた定数465／248で面積を計算します。会派と政党、党の方針と議員個人の見解を同一視しません。

選挙結果と名簿の基準日を分け、最多同数は灰色にします。福岡の推定値、兵庫の算出方法などの注記を保持します。二色の縞模様で他党分を一括表示せず、最多色と全党の人数内訳を表示します。れいわ／いのち、減ゆ／志士を自動で同じ政党・会派にまとめません。

公約・提出案・審議・成立・施行は別の状態です。支持率47.3%は2026-10-11〜13の3調査の単純平均で、最新値でも調査方法の差を補正した値でもありません。不支持未収録を0%にしません。予定を特定の日付に補完せず、要確認の閣僚情報や未確認の政策を注記します。

収録された政策進捗・閣僚・日程・世論情報について、今回すべての一次情報を再検証したものではありません。自動更新ではなく、各項目の時点と出典を確認して使うデモです。政治の基礎知識は、衆議院・参議院の制度解説や日本国憲法へのリンクを付け、これらの日付付き情勢データから分けています。

地図形状は国土地理院「地球地図日本」、GeoJSON変換[dataofjapan/land](https://github.com/dataofjapan/land)に基づく国会マップのものを継承しています。形状を簡略化し、沖縄の位置を移動、一部離島を省略しています。丸い識別マークは政党の公式ロゴではありません。

## 検証

Node.js 22以降で、リポジトリのルートから実行します。

```sh
npm ci
npm test
# 統合版のみ
npm run test:unified
```

開発用依存のlinkedomを使い、データ・議席面積・選挙集計・検索・絞り込み・画面遷移・詳細表示・比較・キーボード操作・政治解説の開閉・フォーカス復帰・検索条件保持を検証します。本番のJavaScriptにはlinkedomを含みません。

実ブラウザの描画・レイアウト・画面操作の検証は未実施です。DOMテストは視覚検証の代わりにはなりません。
